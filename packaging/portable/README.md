# COSTBREAKDOWN Portable

## Launch

Copy this whole folder to a Windows 10 or Windows 11 computer, then double-click `Launch-COSTBREAKDOWN.bat`. It starts a local-only web server with built-in Windows PowerShell and opens COSTBREAKDOWN in the default browser. Keep the launcher window open while using the app; close it to stop the server.

No Node.js, npm, Git, VS Code, administrator account, or network connection is required. Use a current version of Microsoft Edge or Google Chrome.

## User data

Working data is stored in the current browser tab's session storage. It is not a durable company database and is not a shared backup. Export datasets as Excel workbooks and save them to an approved company location to preserve or share work.
