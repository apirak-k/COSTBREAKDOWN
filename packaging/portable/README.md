# COSTBREAKDOWN Portable

Copy this whole folder to a Windows 10 or Windows 11 computer. Double-click `Start COSTBREAKDOWN.exe` to start the local app and open it in the default browser. Double-click `Stop COSTBREAKDOWN.exe` to stop this folder's local server. No installation, Node.js, or npm is required, and no terminal window should remain visible. Use a current version of Microsoft Edge or Google Chrome. Create your own shortcuts if desired.

Working data is scoped to the current browser tab session. It is not a durable company database or shared backup. Export datasets to Excel and save the workbooks to an approved company location to preserve or share work.
