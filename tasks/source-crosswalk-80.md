## Reconciliation classes

- ACCEPTED OVERRIDE — a later explicit user decision changed prior wording or behavior; a matching commit records implementation where available.
- IMPLEMENTATION MATCH — recorded implementation agrees with the current confirmed requirement; it does not make code a source of truth.
- UNRESOLVED GAP — implementation or verification remains incomplete, or a difference has no explicit user decision authorizing it. A verification gap is not by itself proof of a code defect.
- DEFERRED and RECORDED — future scope or process context, not an implementation failure.
- OUT OF SCOPE — a later explicit user decision removed the item from current scope; it is neither TBD nor deferred.

Implementation status and verification status are separate. PASS means evidence was recorded at the cited checkpoint; it does not mean this pass re-ran the check or received human UX acceptance.
